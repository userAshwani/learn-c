## Overview

This is my personal, ongoing C learning log — concepts, notes, and practice
problem solutions (LeetCode/HackerRank-style), written in my own words as I
work through them. Nothing here is copied from a textbook or another site;
it's a running record of what I've actually learned. Maintained by
[Ashwani Tiwari](https://ashwanitiwari.com).

## How this repo is organized

- Notes live in numbered topic folders so they sort in learning order
  (e.g. `01-topic-name/`, `02-topic-name/`, …).
- Each note is a single kebab-case `.md` file inside the topic folder it
  belongs to.
- Every note starts with this exact YAML frontmatter:

  ```yaml
  ---
  title: "Human-readable title"
  description: "One or two sentence summary"
  tags: ["tag-one", "tag-two"]
  difficulty: "beginner" | "intermediate" | "advanced"
  date: "YYYY-MM-DD"
  ---
  ```

This structure is stable on purpose. A script on
[ashwanitiwari.com](https://ashwanitiwari.com) reads this repo and renders
these notes as pages, so once real content exists, the frontmatter contract
above shouldn't change.

## Adding a new note

1. Pick or create the right numbered topic folder.
2. Create the `.md` file, kebab-case, inside it.
3. Add the frontmatter block above, filled in for this note.
4. Write the note in your own words.
5. Use fenced ` ```c ` blocks for reference snippets, and ` ```c run `
   specifically — and only — for short, self-contained examples meant to
   be runnable later on the site.
6. Commit using the message this session gives you.
