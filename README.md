## About

A personal, ongoing C learning log — concepts and practice problem
solutions (LeetCode/HackerRank-style), written in my own words, not copied
from a textbook or another site. Readable directly here on GitHub, and
published as docs pages on [ashwanitiwari.com](https://ashwanitiwari.com).

## Structure

- Notes live in numbered topic folders, sorted in learning order
  (`01-topic-name/`, `02-topic-name/`, …).
- Each note is one kebab-case `.md` file.
- Every note starts with this exact frontmatter — **fixed contract**, since
  a script on ashwanitiwari.com reads this repo and renders these notes as
  pages:

  ```yaml
  ---
  title: "Human-readable title"
  description: "One or two sentence summary"
  tags: ["tag-one", "tag-two"]
  difficulty: "beginner" | "intermediate" | "advanced"
  date: "YYYY-MM-DD"
  ---
  ```

## Adding a new note

1. Pick or create the right numbered topic folder.
2. Create the `.md` file, kebab-case, inside it.
3. Add the frontmatter above, filled in for this note.
4. Write the note in your own words.
5. Use fenced ` ```c ` for reference snippets, ` ```c run ` only for short,
   self-contained examples meant to be runnable on the site.
6. Commit using the message this session gives you.
